# Instruction Set Architecture and Instruction Formats

**Definition:** An instruction set architecture (ISA) defines the operations, registers, data types, and instruction behavior visible to machine-code programs.

## Key points
- An instruction format encodes an operation and the operands or operand locations it uses.
- The ISA is the contract between software and a processor implementation.

## Example
A load instruction in an ISA can copy a value from memory into a general-purpose register.
