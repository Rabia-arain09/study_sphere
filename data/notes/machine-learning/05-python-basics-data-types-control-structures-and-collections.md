# Python Basics: Data Types, Control Structures and Collections

*Machine Learning · Semester 5 · Week 2 · Difficulty 1/5*

**Key concept:** Python's basic types and collections are the building blocks for every data-processing script.

## How it works
- Basic types: int, float, str, bool. Operators: + - * / // % **.
- Control flow: if / elif / else, for loops and while loops.
- **list** is ordered and changeable, **tuple** is ordered and fixed, **set** keeps unique items, **dict** stores key-value pairs.

## Example

```python
marks = [72, 85, 90]
for m in marks:
    if m >= 80:
        print(m, 'distinction')
unique = set([1, 2, 2, 3])   # {1, 2, 3}
```
