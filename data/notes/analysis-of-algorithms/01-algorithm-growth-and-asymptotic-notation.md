# Algorithm Growth and Asymptotic Notation

**Definition:** Asymptotic analysis describes how an algorithm's resource use grows with input size, using notation such as Big O.

## Key points
- Big O gives an asymptotic upper bound and focuses on growth rather than machine-specific timing.
- Constant factors and lower-order terms matter less as input size becomes very large.

## Example
A loop that checks every item in a list has linear O(n) growth.
