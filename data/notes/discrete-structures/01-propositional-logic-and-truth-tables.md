# Propositional Logic and Truth Tables

**Definition:** A proposition is a statement that is either true or false, and logical connectives combine propositions into new statements.

## Key points
- NOT reverses a truth value; AND is true only when both inputs are true.
- A truth table lists every input combination and the resulting truth value.

## Example
If p is true and q is false, p AND q is false.
