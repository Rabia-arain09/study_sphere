# Distributed Systems and Message Passing

**Definition:** A distributed system uses multiple networked computers that coordinate by exchanging messages.

## Key points
- Nodes communicate without sharing one physical memory space.
- Network delay and partial failure mean a message may be late, lost, or answered after a retry.

## Example
A service can send a request to another server and handle a timeout if no reply arrives.
