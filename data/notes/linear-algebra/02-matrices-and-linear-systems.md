# Matrices and Linear Systems

**Definition:** A matrix is a rectangular array of numbers, and a system of linear equations can be represented as Ax=b.

## Key points
- Elementary row operations preserve the solution set when applied consistently to an augmented matrix.
- Gaussian elimination uses row operations to reach a form that makes solutions easier to find.

## Example
The equations x+y=3 and x-y=1 can be written as a two-row matrix system and solved to get x=2, y=1.
