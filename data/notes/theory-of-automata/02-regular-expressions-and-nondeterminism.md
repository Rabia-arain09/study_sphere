# Regular Expressions and Nondeterminism

**Definition:** A regular expression describes a regular language, and a nondeterministic finite automaton may have multiple possible transitions for an input.

## Key points
- A nondeterministic automaton accepts a string if at least one path reaches an accepting state.
- NFAs and DFAs recognize the same class of regular languages.

## Example
The regular expression (0|1)*01 describes binary strings that end in 01.
