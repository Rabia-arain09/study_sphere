# Context-Free Grammars and Pushdown Automata

**Definition:** A context-free grammar uses production rules to generate strings, and a pushdown automaton adds a stack to finite-state memory.

## Key points
- A grammar can describe recursive structures such as nested expressions.
- A pushdown automaton can use its stack to remember unmatched opening symbols.

## Example
A grammar with S -> (S)S | empty can generate balanced parentheses.
