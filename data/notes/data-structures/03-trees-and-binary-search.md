# Trees and Binary Search

**Definition:** A tree is a connected, hierarchical structure of nodes, and a binary search tree orders values to support searching.

## Key points
- Each tree has a root; a node may have children and a leaf has none.
- In a binary search tree, values in the left subtree are smaller and values in the right subtree are larger than the node.

## Example
Searching for 7 in a tree rooted at 5 moves right, then compares 7 with the next node.
