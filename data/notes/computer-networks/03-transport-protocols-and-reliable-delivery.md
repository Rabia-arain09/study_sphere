# Transport Protocols and Reliable Delivery

**Definition:** Transport protocols carry data between application processes and may provide reliability, ordering, or flow control.

## Key points
- TCP provides ordered, reliable delivery using acknowledgments and retransmission.
- UDP has lower protocol overhead but does not guarantee delivery or ordering.

## Example
A file download commonly uses TCP so missing data can be retransmitted.
