# CPU Organization and the Instruction Cycle

**Definition:** A CPU executes program instructions using components such as registers, an arithmetic logic unit, and a control unit.

## Key points
- Registers hold values the CPU needs quickly; the ALU performs arithmetic and logic operations.
- The instruction cycle commonly fetches, decodes, and executes an instruction.

## Example
The CPU fetches an ADD instruction, decodes its operands, and asks the ALU to add their values.
