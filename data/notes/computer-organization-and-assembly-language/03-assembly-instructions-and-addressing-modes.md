# Assembly Instructions and Addressing Modes

**Definition:** Assembly language uses mnemonic instructions that map closely to machine operations, and addressing modes specify where instruction operands are found.

## Key points
- An operand may be an immediate value, a register, or a memory location.
- A load/store instruction set moves values between registers and memory explicitly.

## Example
LOAD R1, [address] means to place the value stored at address into register R1.
