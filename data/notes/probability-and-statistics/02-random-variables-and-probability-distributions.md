# Random Variables and Probability Distributions

**Definition:** A random variable assigns a numerical value to each outcome, and a probability distribution describes the probabilities of its possible values.

## Key points
- Expected value is the probability-weighted average of the outcomes.
- Variance measures how spread out values are around their expected value.

## Example
For a fair six-sided die, the expected result is 3.5 even though a single roll cannot be 3.5.
