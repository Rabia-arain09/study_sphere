# Cache Memory and Locality

**Definition:** A cache is a small, fast memory that keeps copies of recently or frequently used data to reduce average access time.

## Key points
- Temporal locality means recently used data is likely to be used again; spatial locality means nearby data is likely to be used.
- A cache hit finds the requested data in the cache, while a miss requires fetching it from a lower level.

## Example
A loop that processes neighboring array elements often benefits from spatial locality.
