# Classes and Objects

**Definition:** A class defines the data and behavior that its objects can have, and an object is one instance created from that class.

## Key points
- An object stores its own state in fields and exposes behavior through methods.
- A class can be used to create many objects with the same structure but different data.

## Example
A Student class can create two student objects, each with a different name.
