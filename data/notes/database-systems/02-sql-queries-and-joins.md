# SQL Queries and Joins

**Definition:** SQL retrieves and changes relational data, and a join combines rows from tables using a related column.

## Key points
- SELECT chooses columns and WHERE filters rows that meet a condition.
- A join uses matching key values to bring related records together.

## Example
A query can join Students and Enrollments on student_id to list each student's courses.
