# Network Models and Protocols

**Definition:** A network protocol defines rules for exchanging data, and layered models group related communication functions.

## Key points
- Each layer provides services to the layer above and uses services from the layer below.
- Protocols at different layers work together to deliver data between applications.

## Example
A web request can use HTTP at the application layer and IP for network delivery.
