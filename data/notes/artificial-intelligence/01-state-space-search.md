# State-Space Search

**Definition:** State-space search explores possible states and actions to find a path from an initial state to a goal.

## Key points
- Breadth-first search explores by depth; depth-first search follows a branch before backtracking.
- A* uses path cost and a heuristic estimate to prioritize promising states.

## Example
A route planner can treat locations as states and roads as actions leading toward a destination.
