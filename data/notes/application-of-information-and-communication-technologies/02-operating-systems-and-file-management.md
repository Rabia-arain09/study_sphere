# Operating Systems and File Management

**Definition:** An operating system manages a computer's resources and provides services for applications and users.

## Key points
- Files store named information, while folders organize files in a hierarchy.
- A path identifies a file by describing its location in that hierarchy.

## Example
A student saves report.docx inside Documents/Coursework so it can be found by following that path.
