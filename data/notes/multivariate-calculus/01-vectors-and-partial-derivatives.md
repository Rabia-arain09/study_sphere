# Vectors and Partial Derivatives

**Definition:** A multivariable function takes several inputs, and a partial derivative measures its change with respect to one input while the others are held fixed.

## Key points
- A vector can represent a point or direction in a multidimensional space.
- When finding a partial derivative, treat the other independent variables as constants.

## Example
For f(x,y)=x^2+3y, the partial derivative with respect to x is 2x.
