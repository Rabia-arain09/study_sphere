# HTML Document Structure and Elements

*Web Engineering · Semester 5 · Week 1 · Difficulty 1/5*

**Key concept:** An HTML document is a tree of nested elements that describe the content and structure of a page.

## How it works
- Start with <!DOCTYPE html>, then <html> containing <head> and <body>.
- **head:** metadata (title, meta charset, links, scripts). **body:** the visible content.
- An element has an opening tag, content and a closing tag. Some are empty, such as <br> and <img>.
- **Attributes** add information, for example href and src.
- Headings run from <h1> to <h6>.

## Example

A minimal valid page:

```html
<!DOCTYPE html>
<html>
  <head><title>My Page</title></head>
  <body><h1>Hello</h1></body>
</html>
```
