# The Internet and the World Wide Web

*Web Engineering · Semester 5 · Week 1 · Difficulty 1/5*

**Key concept:** The Internet is the global network of networks. The World Wide Web is a service that runs on it.

## How it works
- The **Internet** is the hardware and protocols (TCP/IP) that connect computers.
- The **Web** is a collection of linked **hypertext** documents accessed over the Internet using HTTP.
- Email, file transfer and streaming also use the Internet but are not the Web.
- Tim Berners-Lee invented the Web in 1989-1991 at CERN.

## Example

Sending an email uses the Internet but not the Web. Opening a page in a browser uses both.
