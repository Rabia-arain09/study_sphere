# Normalization and Transactions

**Definition:** Normalization organizes tables to reduce repeated facts, while a transaction groups database operations into one reliable unit.

## Key points
- Good normalization helps prevent update, insertion, and deletion anomalies.
- A transaction should satisfy atomicity, consistency, isolation, and durability (ACID).

## Example
A bank transfer subtracts from one account and adds to another in one transaction so both changes succeed together.
