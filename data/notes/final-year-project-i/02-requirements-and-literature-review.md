# Requirements and Literature Review

**Definition:** Requirements describe what a project should do, while a literature review compares relevant prior work to explain the project context.

## Key points
- Functional requirements describe behavior; quality requirements describe constraints such as performance or usability.
- A useful literature review groups and evaluates sources rather than listing them without connection.

## Example
A team can review existing navigation tools, then define a requirement that users can search by building name.
