# Transactions and Concurrency Control

**Definition:** Concurrency control coordinates simultaneous transactions so their combined effects remain consistent.

## Key points
- Isolation prevents a transaction from observing inappropriate intermediate changes by another transaction.
- Locks or other concurrency techniques help prevent conflicts such as lost updates.

## Example
If two transactions update one account, the database must coordinate them so one update does not overwrite the other.
