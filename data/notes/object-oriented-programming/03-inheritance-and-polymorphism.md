# Inheritance and Polymorphism

**Definition:** Inheritance lets a class reuse or extend another class, while polymorphism lets different objects respond to the same operation in their own way.

## Key points
- A derived class can override a method to provide specialized behavior.
- Code can use a shared parent type without knowing each object's specific class.

## Example
A list of shapes can call area() on both a circle and a rectangle, and each computes its own area.
