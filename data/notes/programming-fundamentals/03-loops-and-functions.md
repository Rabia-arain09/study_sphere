# Loops and Functions

**Definition:** A loop repeats instructions, while a function is a named reusable block that can accept inputs and return a result.

## Key points
- Use a loop when similar work must be repeated for several values.
- Use a function to give a task a clear name and avoid repeating its implementation.

## Example
A square(n) function can return n * n, and a loop can call it for each value in a list.
