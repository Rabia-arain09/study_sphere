# Web Browsers

*Web Engineering · Semester 5 · Week 1 · Difficulty 1/5*

**Key concept:** A browser requests web resources, then renders HTML, CSS and JavaScript into a page the user can see and use.

## How it works
- **Main parts:** user interface, browser engine, rendering engine, networking, JavaScript interpreter and data storage.
- The **rendering engine** parses HTML and CSS and paints the page (Blink, Gecko, WebKit).
- **Add-ons** (extensions) change browser behaviour. **Plugins** display content the browser cannot handle itself and are now largely obsolete.
- **Cookies** are small pieces of data a site stores in the browser.

## Example

Chrome and Edge use the Blink engine, Firefox uses Gecko and Safari uses WebKit. The same page can look slightly different in each.
