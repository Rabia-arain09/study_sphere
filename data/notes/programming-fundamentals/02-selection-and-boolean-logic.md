# Selection and Boolean Logic

**Definition:** A selection statement chooses which program path to run by evaluating a condition that is true or false.

## Key points
- Comparison operators such as == and < create Boolean conditions.
- Combine conditions with and, or, and not when a decision has several parts.

## Example
If score >= 50 is true, a program can print "Pass"; otherwise it can print "Try again".
