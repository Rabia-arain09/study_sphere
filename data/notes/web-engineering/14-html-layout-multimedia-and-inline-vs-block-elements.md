# HTML Layout, Multimedia and Inline vs Block Elements

*Web Engineering · Semester 5 · Week 1 · Difficulty 2/5*

**Key concept:** Semantic layout tags describe the role of page regions, and elements behave as either block or inline.

## How it works
- **Semantic layout:** <header>, <nav>, <main>, <section>, <article>, <aside>, <footer>.
- **Multimedia:** <img src alt>, <audio controls>, <video controls>.
- **Block** elements (div, p, h1) start on a new line and fill the width.
- **Inline** elements (span, a, strong) flow within a line and take only the space they need.
- Semantic tags help accessibility and search engines.

## Example

<p>Hello <span>world</span></p>: the p is block and takes a full line, the span is inline and stays inside the sentence.
