# Data Representation and Number Systems

**Definition:** Digital hardware represents information with bits, and number systems such as binary and hexadecimal provide ways to write those values.

## Key points
- Binary uses base 2; hexadecimal uses base 16 and each hex digit maps to four bits.
- Two's complement represents signed integers and supports addition with the same hardware used for unsigned values.

## Example
The binary value 1111 0000 is F0 in hexadecimal.
