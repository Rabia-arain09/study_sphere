# Database Indexing and Query Planning

**Definition:** A database index is an auxiliary structure that helps locate rows without scanning an entire table, and a query plan describes how the database will execute a query.

## Key points
- An index can speed up lookups but requires storage and maintenance when data changes.
- A query optimizer compares possible operations and chooses a plan based on estimated cost.

## Example
An index on student_id can help find one student without reading every row in the table.
