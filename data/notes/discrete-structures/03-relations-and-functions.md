# Relations and Functions

**Definition:** A relation is a set of ordered pairs, and a function is a relation that assigns each input exactly one output.

## Key points
- The domain is the set of inputs and the codomain is the set of allowed outputs.
- Different inputs may share an output, but one input cannot have two outputs in a function.

## Example
The rule f(x)=x+1 maps input 2 to output 3.
