# Arrays and Linked Lists

**Definition:** An array stores elements in indexed positions, while a linked list stores elements in nodes connected by references.

## Key points
- Array indexing is fast when the index is known; inserting in the middle may require shifting elements.
- Linked lists can insert by changing links, but finding an item usually requires traversal.

## Example
A playlist can use linked nodes so the next song points to the following song.
