# Problem Selection and Project Scope

**Definition:** A project problem states a need or question to address, and project scope defines the work and limits of the proposed solution.

## Key points
- A focused problem should be important, understandable, and feasible within available time and resources.
- A clear scope states what the project will and will not deliver.

## Example
A campus navigation project can limit its first release to building search and accessible walking routes.
