# Deterministic Finite Automata and Regular Languages

**Definition:** A deterministic finite automaton has a finite set of states and exactly one transition for each state and input symbol.

## Key points
- The machine accepts a string when processing it ends in an accepting state.
- Finite automata recognize regular languages.

## Example
A DFA can recognize binary strings whose last symbol is 1 by tracking whether the most recent symbol was 1.
