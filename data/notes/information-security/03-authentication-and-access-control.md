# Authentication and Access Control

**Definition:** Authentication verifies an identity, while access control decides which actions an authenticated identity may perform.

## Key points
- Use unique credentials and additional factors to reduce the risk of account takeover.
- Least privilege grants only the permissions needed for a task.

## Example
A library system verifies a staff login and then allows that role to update book records but not student grades.
