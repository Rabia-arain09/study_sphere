# Sequential Circuits and State

**Definition:** A sequential circuit uses stored state as well as current inputs to determine its output.

## Key points
- Latches and flip-flops can store binary state.
- A clocked circuit changes state in response to clock events, allowing coordinated operation.

## Example
A counter uses flip-flops to remember its current number and update it on each clock pulse.
