# 2D Transformations and Coordinate Systems

**Definition:** A graphics transformation changes an object's position, size, or orientation in a coordinate system.

## Key points
- Translation moves an object; scaling changes its size; rotation changes its orientation.
- The order of transformations can affect the final result.

## Example
A game moves a character by translating its shape, then rotates it to face a new direction.
