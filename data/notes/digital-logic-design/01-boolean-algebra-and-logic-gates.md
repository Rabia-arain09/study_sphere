# Boolean Algebra and Logic Gates

**Definition:** Boolean algebra uses true/false values and logical operations, while logic gates implement those operations in digital hardware.

## Key points
- AND, OR, and NOT are basic gates; their outputs follow truth-table rules.
- Boolean identities can simplify a logic expression without changing its behavior.

## Example
The expression A AND NOT B is true only when A is true and B is false.
