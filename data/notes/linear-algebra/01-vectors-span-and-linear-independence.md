# Vectors, Span, and Linear Independence

**Definition:** A vector is an ordered list of numbers, and a linear combination scales vectors and adds the results.

## Key points
- The span is the set of all linear combinations of a collection of vectors.
- Vectors are linearly independent when no vector in the collection can be formed from the others.

## Example
The vector (3,1) is 2(1,0)+(1,1), so it is in the span of (1,0) and (1,1).
