# Bootstrap Components

*Web Engineering · Semester 5 · Week 2-3 · Difficulty 2/5*

**Key concept:** Bootstrap provides ready-made interface components that work with just classes and attributes.

## How it works
- **alert:** coloured message boxes (alert alert-success).
- **card:** content box with a body, title and image.
- **navbar:** responsive navigation bar that collapses on small screens.
- **modal:** dialog opened with data-bs-toggle="modal".
- **carousel, accordion, forms, buttons, badges, list groups** and more.
- Components need Bootstrap's JavaScript for behaviour such as collapsing and modals.

## Example

A success alert and a primary button:

```html
<div class="alert alert-success">Saved!</div>
<button class="btn btn-primary">Submit</button>
```
