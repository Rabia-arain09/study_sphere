# IP Addresses, IPv4 and IPv6

*Web Engineering · Semester 5 · Week 1 · Difficulty 2/5*

**Key concept:** An IP address identifies a device on a network. IPv4 uses 32 bits and IPv6 uses 128 bits.

## How it works
- **IPv4:** four decimal numbers 0-255, such as 192.168.1.10. About 4.3 billion addresses (2^32).
- **IPv6:** eight groups of hex digits, such as 2001:db8::1. Vastly larger (2^128).
- IPv6 was created because IPv4 addresses ran out.
- **Private ranges** (for example 192.168.x.x) are used inside local networks and reached from outside via NAT.

## Example

2^32 = 4,294,967,296 IPv4 addresses. The IPv4 address 192.168.1.10 is 4 bytes, so it is 32 bits.
