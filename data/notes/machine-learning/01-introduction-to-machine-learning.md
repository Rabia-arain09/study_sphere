# Introduction to Machine Learning

*Machine Learning · Semester 5 · Week 1 · Difficulty 1/5*

**Key concept:** Machine learning lets a computer learn patterns from data instead of following rules written by a programmer.

## How it works
- Traditional programming: rules + data produce answers. Machine learning: data + answers produce the rules (the model).
- **Supervised learning** uses labeled data and predicts a label (classification) or a number (regression).
- **Unsupervised learning** uses unlabeled data and finds structure, such as clusters or hidden patterns.
- **Reinforcement learning** trains an agent through rewards and penalties for its actions.

## Example

A spam filter learns from emails labeled spam or not spam (supervised). Grouping customers by buying habits needs no labels (unsupervised). A game-playing bot that improves by winning and losing is reinforcement learning.
