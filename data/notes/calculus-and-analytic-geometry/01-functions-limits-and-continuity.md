# Functions, Limits, and Continuity

**Definition:** A function assigns each input exactly one output, and a limit describes the value its outputs approach near an input.

## Key points
- A function is continuous at a point when its value matches the limit there.
- Limits help describe behavior even when a function is not defined at the point itself.

## Example
For f(x)=x+2, as x approaches 3, f(x) approaches 5.
