# Documentation, Presentation, and Maintenance

**Definition:** Project documentation explains how a system is built or used, a presentation communicates its purpose and results, and maintenance updates it after delivery.

## Key points
- Clear setup instructions help another person run the project.
- A handover should identify known limitations, dependencies, and future work.

## Example
A project team can provide a README, demonstrate the main workflow, and list a known feature limitation.
