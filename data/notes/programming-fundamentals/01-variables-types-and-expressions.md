# Variables, Types, and Expressions

**Definition:** A variable is a named reference to a value, a data type describes the values and operations that are valid, and an expression combines values and operators to produce a result.

## Key points
- Choose a type that fits the value and the operations you need.
- Use parentheses to make the intended order of operations clear.

## Example
Set price to 4.0 and quantity to 3; price * quantity evaluates to 12.0.
