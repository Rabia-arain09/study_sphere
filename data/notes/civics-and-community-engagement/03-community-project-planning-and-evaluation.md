# Community Project Planning and Evaluation

**Definition:** A community project plan connects a defined need to activities, responsibilities, resources, and measurable outcomes.

## Key points
- Set realistic objectives and decide how progress will be checked.
- Evaluation compares results with objectives and uses lessons to improve future work.

## Example
A cleanup project can record the area covered and participant count, then compare them with its targets.
