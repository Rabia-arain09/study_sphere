# Methods, Constructors, and Encapsulation

**Definition:** A constructor initializes a new object, methods define its behavior, and encapsulation protects its internal state behind a clear interface.

## Key points
- A method can read or update fields according to the class rules.
- Encapsulation helps prevent invalid changes by controlling access to data.

## Example
A BankAccount constructor sets an opening balance, while a deposit method accepts only a positive amount.
