# Relational Tables, Rows, and Keys

**Definition:** A relational database stores related data in tables whose rows are records and whose columns are attributes.

## Key points
- A primary key uniquely identifies each row in its table.
- A foreign key refers to a key in another table to represent a relationship.

## Example
A Students table can use student_id as its primary key, and Enrollments can store that ID as a foreign key.
