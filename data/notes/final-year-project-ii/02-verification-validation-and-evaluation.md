# Verification, Validation, and Evaluation

**Definition:** Verification checks whether a system meets its specified requirements, validation checks whether it solves the users' problem, and evaluation measures its results.

## Key points
- Use test cases linked to requirements so important behavior can be checked systematically.
- Evaluation should use suitable measures and report limitations as well as successes.

## Example
A team can verify that a search returns matching records, then ask users whether the results help them find what they need.
