# Greedy Algorithms and Dynamic Programming

**Definition:** A greedy algorithm repeatedly makes a locally best choice, while dynamic programming stores solutions to overlapping subproblems.

## Key points
- A greedy choice is correct only when the problem has properties that make local choices safe.
- Dynamic programming is useful when subproblems overlap and an optimal solution can be built from their results.

## Example
For a suitable coin system, a change-making method can reuse computed results for smaller amounts.
