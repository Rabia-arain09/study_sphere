# Requirements and Use Cases

**Definition:** Software requirements describe what a system must do and the constraints it must satisfy.

## Key points
- Functional requirements state system behavior; nonfunctional requirements describe qualities such as performance or security.
- Use cases describe interactions between an actor and the system to achieve a goal.

## Example
A library system use case can describe a member searching for and borrowing an available book.
