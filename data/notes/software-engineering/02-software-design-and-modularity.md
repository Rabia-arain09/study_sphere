# Software Design and Modularity

**Definition:** Software design defines how a system is organized, and modularity divides it into parts with clear responsibilities.

## Key points
- High cohesion keeps related work together inside a module.
- Low coupling reduces unnecessary dependence between modules.

## Example
A payment module can expose a small interface while hiding the details of contacting a payment provider.
