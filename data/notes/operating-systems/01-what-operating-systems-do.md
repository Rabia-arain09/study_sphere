# What Operating Systems Do

*Operating Systems · Semester 5 · Week 1 · Difficulty 1/5*

**Key concept:** An operating system (OS) manages the hardware and gives programs a common, safe way to use it.

## How it works
- **User view:** on a phone or PC the OS aims at ease of use; on a server it aims at sharing resources fairly.
- **System view:** the OS is a **resource allocator** (CPU, memory, storage, I/O) and a **control program** that stops programs from misusing the hardware.
- The **kernel** is the one program that runs all the time. Everything else is a system program or an application.
- Middleware (databases, graphics, messaging) sits between the kernel and applications.

## Example

Two programs send a print job at the same moment. The OS queues the jobs and sends them one at a time, so the pages do not interleave. This is the resource-allocator role.

## Real-world use

Android, Windows and Linux all do this job, each tuned for a different kind of device.
