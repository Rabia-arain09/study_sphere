# Computer Components and Data Representation

**Definition:** A computer system uses hardware to process and store data, and represents digital information with bits grouped into larger units.

## Key points
- The CPU executes instructions; RAM holds data currently in use; storage keeps data when power is off.
- A bit has value 0 or 1, and eight bits make one byte.

## Example
A photo saved on a phone is kept in storage as digital data and copied into RAM when an app opens it.
