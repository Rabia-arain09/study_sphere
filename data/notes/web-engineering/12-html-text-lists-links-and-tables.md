# HTML Text, Lists, Links and Tables

*Web Engineering · Semester 5 · Week 1 · Difficulty 1/5*

**Key concept:** Basic HTML tags format text, organize items into lists, connect pages and show data in tables.

## How it works
- **Text:** <p>, <strong>, <em>, <br>, <hr>.
- **Lists:** <ul> (bulleted), <ol> (numbered), <li> items.
- **Links:** <a href="url">text</a>. A navbar is often a list of links in <nav>.
- **Tables:** <table>, <tr> rows, <th> header cells, <td> data cells.

## Example

A link and a small table:

```html
<a href="about.html">About</a>
<table>
  <tr><th>Name</th><th>Marks</th></tr>
  <tr><td>Ali</td><td>85</td></tr>
</table>
```

2. What is the difference between th and td?
