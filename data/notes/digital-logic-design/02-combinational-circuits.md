# Combinational Circuits

**Definition:** A combinational circuit produces outputs from its current inputs without storing a previous state.

## Key points
- A truth table specifies the output for every possible input combination.
- Adders and multiplexers are common combinational building blocks.

## Example
A half adder takes two one-bit inputs and produces a sum bit and a carry bit.
