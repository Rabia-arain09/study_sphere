# Measurement, Units, and Vectors

**Definition:** Measurement assigns a numerical value and unit to a physical quantity, while a vector has both magnitude and direction.

## Key points
- Use consistent SI units when substituting values into physical equations.
- A measured value has uncertainty, so its reported precision should match the measurement method.

## Example
A displacement of 5 metres east is a vector with magnitude 5 metres and an eastward direction.
