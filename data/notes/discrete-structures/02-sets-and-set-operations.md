# Sets and Set Operations

**Definition:** A set is a well-defined collection of distinct elements, and set operations form new sets from existing ones.

## Key points
- The union contains elements in either set; the intersection contains elements in both.
- Set difference contains elements in the first set but not the second.

## Example
For A={1,2} and B={2,3}, A union B is {1,2,3}, while A intersection B is {2}.
