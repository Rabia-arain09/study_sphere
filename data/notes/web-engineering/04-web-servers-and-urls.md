# Web Servers and URLs

*Web Engineering · Semester 5 · Week 1 · Difficulty 2/5*

**Key concept:** A web server stores resources and sends them on request, and a URL tells the browser exactly which resource to ask for.

## How it works
- A **web server** (Apache, Nginx, IIS) listens for HTTP requests and returns files or generated content.
- A **URL** has parts: scheme, host, port, path, query string and fragment.
- The default ports are 80 for HTTP and 443 for HTTPS.
- Static content is sent as stored. Dynamic content is generated by code first.

## Example

In https://shop.example.com:443/items/list?page=2#top the scheme is https, the host is shop.example.com, the path is /items/list, the query is page=2 and the fragment is top.
