# Testing and Quality Assurance

**Definition:** Software testing checks program behavior against expected results, and quality assurance uses planned practices to improve reliability.

## Key points
- Unit tests check small components; integration tests check how components work together.
- A test can expose a defect, but passing tests do not prove that no defects exist.

## Example
A unit test checks that a tax calculation returns the expected value for a known input.
