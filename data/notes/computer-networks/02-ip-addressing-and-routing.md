# IP Addressing and Routing

**Definition:** An IP address identifies a network interface, and routing selects a path for packets to reach another network.

## Key points
- A subnet prefix identifies which address bits represent the network.
- Routers compare destination addresses with routing information to choose a next hop.

## Example
A router forwards a packet toward the next network listed for its destination prefix.
