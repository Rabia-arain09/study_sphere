# Website vs Web Application and Categories of Web Applications

*Web Engineering · Semester 5 · Week 1 · Difficulty 2/5*

**Key concept:** A website mainly presents information. A web application lets users do tasks and interact with data.

## How it works
- **Website:** mostly static content to read, such as a brochure or blog.
- **Web application:** user input, logic and a database, such as online banking.
- **Categories:** document-centric, interactive, transactional, workflow-based, collaborative, portals, and data-warehousing or social-network applications.
- Applications are harder to build because they must manage state, security and data.

## Example

A university's About page is a website. The student portal where you register for courses and see grades is a web application (transactional).
